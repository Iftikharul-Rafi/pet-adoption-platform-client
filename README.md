# 🐾 Pet Adoption Platform (Client)

Frontend of a full-stack MERN based Pet Adoption Platform built with Next.js.

---

# 🌐 Live Site

https://client-six-tau-53.vercel.app/

---

# 📌 Purpose

This client-side application allows users to:

- Browse available pets
- View pet details
- Submit adoption requests
- Manage personal pet listings
- Approve or reject adoption requests

The UI is fully responsive and provides a smooth user experience with secure authentication.

---

# 🚀 Features

- 🔐 JWT Authentication
- 🍪 HTTPOnly Cookie Based Login System
- 🐶 Add New Pets
- ✏️ Update & Delete Pet Listings
- ❤️ Adoption Request System
- 📩 Approve / Reject Requests
- 🔎 Search & Filter Pets
- 🌙 Dark Mode UI
- 📱 Fully Responsive Design
- 🚫 Custom 404 Not Found Page
- ⚡ Toast Notifications
- 🔒 Protected Routes

---
